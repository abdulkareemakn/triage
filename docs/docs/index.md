# Triage developer guide

These guides preserve the original MERN starter's development patterns for Triage. They cover setup, client and server code, tests, and deployment. Some examples still use Launchpad names or example features. Check the current Triage code and root `WORKFLOW.md` before applying them; product requirements live in `PRODUCT.md` and OpenSpec.

- [Start here](/installation/prerequisites): install tools and run the workspace.
- [Design and UI](/build/design-system): establish the Triage interface before adding screens.
- [Build your app](/build/): follow the existing data, auth, validation, API, and client patterns.
- [Code quality](/quality/): format, lint, typecheck, and test.
- [Deployment](/deployment/): understand the Railway and Docker paths.
- [Reference](/reference/): find scripts, endpoints, and security guidance.
